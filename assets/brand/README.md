## Ikona aplikacji (= logo-znak)

**Dwa złote kłosy pochylone w prawo** to ikona aplikacji — nie wordmark.

| Plik | Opis |
|------|------|
| `/assets/icons/logo-master.svg` | **Ikona aplikacji (master)** |
| `logo-on-light.svg` / `.png` | Ta sama ikona na jasnym |
| `logo-on-dark.svg` / `.png` | Ta sama ikona na ciemnym |
| `logo-mark.svg` / `.png` | Kłosy bez tła (nakładka) |

Nazwa „Regionaler Geschmack” = tekst obok ikony (Literata), nigdy wewnątrz pliku ikony.

```bash
npm run generate-icons
```
