# Store assets

Ikony Google Play i App Store pochodzą wyłącznie z `assets/icons/logo-master.svg`.

```bash
npm run generate-icons
```

| `google-play/feature-graphic-source.png` | Przytnij do **1024×500** |
| `app-store/icon-1024.png` | App Store |
