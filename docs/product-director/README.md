# AI Product Director (ETAP 27)

Codzienny **mózg produktu** — przegląd biznesowy, nie tylko raport techniczny.

## 8 pytań

1. Co poprawić?
2. Co usunąć?
3. Co uprościć?
4. Co spowalnia aplikację?
5. Co denerwuje użytkownika?
6. Co zwiększy liczbę powrotów?
7. Jak wygląda konkurencja?
8. Czy produkt jest lepszy niż miesiąc temu?

## Źródła

Health · Improvement · Virtual User · Real Users · Emotion AI · Living Brand · Daily · Advisor · Quality Loop · archiwum Directora

## Polityka

- **autoFix: false**
- advisoryOnly — Ty zatwierdzasz decyzje
- Porównanie „miesiąc temu” rośnie wraz z archiwum `docs/product-director/YYYY-MM-DD.json`

## CLI

```bash
npm run director
npm run check:director
```

→ `docs/product-director/latest.md`

