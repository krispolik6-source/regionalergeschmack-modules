# Doradca Projektu (ETAP 18E)

Codzienny briefing produktowy. **Nie naprawia kodu** — tylko odpowiada na pytania.

## Pytania

1. Co dziś można ulepszyć?
2. Co najbardziej irytuje użytkowników?
3. Które ekrany są najsłabsze?
4. Jak poprawić wydajność?
5. Jak poprawić wygląd?
6. Jak zwiększyć liczbę powrotów użytkowników?
7. Co warto dodać w następnej wersji?

## Źródła

Health · Learning · Improvement Engine · Virtual User (lokalnie)

## Uruchomienie

```bash
npm run health
npm run improve
npm run advisor
```

W aplikacji (dev): panel Health → **Doradca** · `__RG_ADVISOR__.run()`

Pliki: `docs/advisor/latest.md` · `YYYY-MM-DD.md`
