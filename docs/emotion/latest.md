## Wymiary emocji

### climate — 93%

- Motyw sezonowy / climate-ready buduje nastrój pór roku
- Warstwa climate (promienie / trawa) dodaje głębi
- Ambient natury dostępny (opcjonalnie) — potencjał immersji

### colors — 96%

- Ciepła paleta (zieleń / złoto / cream / wheat) — regionalny klimat
- Brak dominującego zimnego niebieskiego
- Silne kotwice brandowe w CSS (8)

### photos — 88%

- Bogata obecność obrazów (80) — miejsce i produkt widać
- Większość obrazów ma opis (alt) — szacunek i kontekst
- Zdjęcia wyglądają na autentyczne / produktowe

### textLoad — 82%

- Mało tekstu — przestrzeń na obraz i nastrój
- Nagłówki nadają rytm, nie ścianę

### fatigue — 50%

- Za dużo CTA (12) — wybór męczy

### friendliness — 100%

- Powitanie / ludzki ton na starcie
- Ciepłe sformułowania (region, smak, lokalność)
- Puste stany zadbane — nie zostawiają użytkownika samego
- Miękkie kształty UI (przyjazność wizualna)
- UX health wspiera poczucie „tu jest okej”
